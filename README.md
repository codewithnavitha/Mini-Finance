## 💰 About the Project

**Mini Finance** is a modern financial dashboard designed to provide users with a convenient way to view and manage their financial information through a clean and intuitive interface.

The dashboard brings essential financial information together in one place, including account balances, transaction history, currency exchange rates, and money transfer options.

The project focuses on creating a simple, organized, and user-friendly banking experience.

## ✨ Features

- **Dashboard Overview:** Displays account balance and essential financial information.
- **Account Details:** Shows card information, cardholder details, and validity.
- **Transaction History:** Displays recent financial transactions and payment activities.
- **Currency Exchange:** Provides exchange rate information for multiple international currencies.
- **Money Transfer:** Includes quick-action options for sending and requesting money.
- **Payment Options:** Includes Top Up and Scan & Pay actions.
- **Notifications:** Displays account updates and important notifications.
- **User Profile:** Provides access to profile details and account settings.
- **Responsive Interface:** Designed for a clean and accessible dashboard experience.
